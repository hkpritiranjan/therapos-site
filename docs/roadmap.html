Roadmap

Quarterly milestones from MVP to platform. The rule at every stage: when choosing between a CRUD feature and AI that saves 30 minutes — choose AI. Every quarter earns the right to build the next one.

✦
Guiding principle

Each phase ships only after the previous phase's success metric is hit. Q4 2026 doesn't start until Q3's 60%+ week-4 retention target is achieved. Ship less, ship right.

Q3 2026 — In build
MVP — The Smallest Product That Creates Real Value
In build
  • Secure therapist signup and login — API is built (email and password, JWT); web login screen and MFA are not
  • Therapist onboarding — license type, primary modality, timezone
  • Patient profiles — name, concerns, diagnoses, modality, session frequency, status
  • Session creation and lifecycle (Scheduled → In Progress → Completed → Cancelled)
  • Raw notes input — plain text area, voice-to-text via browser native API
  • AI SOAP/DAP/BIRP/Free note generation — streaming via SSE, 8–12 second generation
  • Editable note fields — Tiptap rich text editor, field-level editing
  • Note finalization — one-click commit, triggers memory pipeline
  • Session prep brief — AI-generated before every session from session 2 onward
  • Treatment goals — create, track progress, update status (Active/Achieved/Paused/Abandoned)
  • Patient session timeline — chronological view of all sessions and goals
  • Dashboard — today's sessions, recent patients, quick actions
  • Privacy hardening — pseudonymise identifiers before AI calls; keep raw notes off analytics and optionally off the AI path
  • Provenance — every summary sentence links to its source note; copy-ready export to the therapist's EHR
  • Compliance foundation (launch gate) — audit logging, encryption controls, executed BAAs, MFA, TLS. None are complete yet; see the build status.
✓
Q3 success signal

Therapist generates first AI note within 10 minutes of signup. Returns for session 2 without prompting. Week-4 retention >60%. NPS >50.

Q4 2026
Memory + Search — The Intelligence Layer
Planned

  • Note embedding pipeline — every finalized note → text-embedding-3-small → pgvector
  • Natural language search — pgvector cosine similarity across all session history
  • ⌘K command palette — global search across patients, notes, and actions
  • Homework generator — AI suggests 3 options post-session, tracks completion
  • Patient profile improvements — AI summary visible and editable, session stats
  • Stripe billing integration — 30-day trial, Solo + Clinic plans, webhooks
  • Referral program — unique links, "give 1 month, get 1 month" reward
  • Data export — JSON full export, patient PDF export

25%+ of users use NL search within 30 days of feature launch. Trial-to-paid conversion >20%. First 50 paying customers.

What We Will Not Build

Staying out of adjacent categories is a product discipline. The list of things we won't build is as important as the roadmap.

FeatureTimelineWhy not
Billing & insurance claimsV3 at earliestNot our category. SimplePractice owns this. Competing would require an EHR pivot that alienates our current users.
Telehealth videoV3 at earliestDoxy.me and Zoom for Healthcare already solved this. Integration beats rebuilding a solved problem.
Patient-facing portalV2 maybeTherapist is the customer. A patient portal changes the ICP and doubles the support surface area.
Medication managementNever MVPRequires prescriber workflows and NPI-level compliance. Different ICP entirely (psychiatrists, not therapists).
Hospital / inpatient EHRNeverDifferent regulatory environment, different buyer (procurement), different product. Explicit non-goal.
Native mobile appV2Desktop first. Therapists document on desktop computers. Mobile is convenience, not a core need in the short term.
AI diagnosisNeverFDA SaMD classification risk. Clinical liability risk. TherapOS is documentation software, not a clinical decision support tool.
Group/family therapy specialized toolsV2Individual therapy is 85% of the market. Session type is supported, but specialized group note formats are V2.
ℹ
Staged roadmap with gates

The 3 / 6 / 12 / 24-month horizons, entry conditions and the gated patient-activity pilot are in Competitors & Strategy §15. Patient-facing features are exploratory until the continue/pivot/stop gates (§14) pass.

How We Decide What to Ship Next

Three criteria determine priority order:

  1. Retention impact: Does this improve week-4 or month-3 retention? Features that touch the compound memory loop (notes, prep, search, goals) always win.
  2. Therapist asked for it unprompted: Requested features score higher than features we hypothesize would be valuable. We run weekly calls with active users.
  3. Can we ship it in 2 weeks? If a feature takes longer than 2 weeks, it probably means we haven't thought hard enough about scope. Break it down.
