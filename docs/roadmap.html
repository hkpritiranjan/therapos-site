Roadmap

Quarterly milestones from MVP to platform. The rule at every stage: when choosing between a CRUD feature and AI that saves 30 minutes, choose AI.

Q3 2026 — Now
MVP — The Smallest Product That Creates Real Value
  • Secure therapist signup + login (Clerk)
  • Patient profiles — name, concerns, diagnosis, modality
  • Session creation and management
  • Raw notes input → AI SOAP/DAP note generation (streaming)
  • Editable note fields — full therapist control
  • Session prep brief — AI-generated before every session
  • Treatment goals (CRUD + progress notes)
  • Patient session timeline
  • Dashboard — today's sessions, recently viewed
  • HIPAA-ready foundation — encryption, audit logs, BAA
MVP success signal

Therapist generates first AI note within 10 min of signup. Returns for session 2 without prompting. Says "this saved me 20 minutes" unprompted.

Q4 2026
Memory + Search — The Intelligence Layer
  • Rolling AI patient summary — updated after every finalized note
  • Natural language search — pgvector across all session history
  • Homework generator — AI suggests 3 options post-session
  • ⌘K command palette — search patients, notes, sessions globally
  • Note embedding pipeline — every finalized note becomes searchable
  • Billing integration — Stripe subscriptions, 14-day trial
  • Referral program — "give 1 month, get 1 month"
Q1 2027
Insights — Progress Becomes Visible
  • Goal progress timeline — visual chart across sessions
  • Cross-session pattern recognition — AI surfaces themes over months
  • Mood and affect trend tracking
  • Risk flag nudges — soft alerts for concerning language in notes
  • Progress report export — PDF for supervisors or insurance
  • Session statistics — duration, frequency, gap analysis
Q2 2027
Collaboration — Small Clinics
  • Multi-therapist clinic accounts — per-seat billing
  • Admin dashboard — practice owner sees all therapists
  • Supervisor review — flag notes for supervision
  • Shared patient transfers — when a patient changes therapists
  • Clinic-wide search and analytics
Q3 2027
India Launch — New Market
  • India pricing tier — ₹1,499/month Solo, ₹2,499/seat Clinic
  • Razorpay payment integration
  • DPDP Act compliance — Indian data stored in AWS ap-south-1
  • Data Protection Officer appointment
  • India-specific onboarding — local mental health licensing context
Q4 2027
Platform — Content and Integrations
  • Worksheet library — CBT, DBT, EMDR templates
  • Session templates by modality
  • Modality packs — structured protocols (CBT for anxiety, DBT skills)
  • Calendar integration — pull upcoming sessions from Google Cal
  • Public API — allow integrations with scheduling tools
2028+
Network — Compound Intelligence
  • UK and Canada expansion
  • Payer integrations — outcome reporting for value-based care
  • De-identified outcome research — aggregate insights across all sessions
  • CE credit partnership — AI ethics module for therapists
  • Referral network — match patients to therapists on the platform
  • API revenue — other tools integrate TherapOS clinical memory
