System Architecture

TherapOS is a monorepo (Turborepo) with a Next.js frontend and a NestJS API. PostgreSQL with pgvector handles both relational data and vector search. All AI calls are async — the product works without AI as a fallback.

Key Architectural Decisions

1. Monolith first, microservices later

The NestJS API is a single deployable unit. AI processing, search, and data are all in one service. Extract the AI module into a separate service only when you need independent scaling — at approximately 10,000 active users.

2. pgvector over Pinecone for MVP

Pinecone adds infrastructure complexity and cost. pgvector in PostgreSQL handles millions of embeddings efficiently with HNSW indexing. Migrate to Pinecone when you exceed 500k note embeddings or need metadata filtering complexity that pgvector can't support cleanly.

3. BullMQ for all AI jobs

Note generation streams directly to the client via Server-Sent Events (SSE). Embedding and patient summary refresh run asynchronously via BullMQ after note finalization. The product is never blocked waiting for AI.

4. SSE over WebSockets for streaming

AI note generation streams token-by-token to the frontend using Server-Sent Events. SSE is simpler than WebSockets for one-directional streaming and works through HTTP/2 without special infrastructure.

Security Architecture

Encryption

  • At rest: AWS RDS encryption (AES-256). Sensitive fields (patient name, DOB, email) additionally encrypted at the application layer using envelope encryption.
  • In transit: TLS 1.3 enforced. HSTS headers set. No HTTP fallback.
  • Keys: AWS KMS for key management. Keys rotated annually.

Access control

  • Every API endpoint is guarded by ClerkGuard — verifies JWT, extracts therapist ID.
  • Every patient/session/note query is scoped to the authenticated therapist's ID. Row-level isolation enforced in every Prisma query.
  • No endpoint exposes data across therapist accounts — verified by automated tests.

Audit logging

An NestJS interceptor logs every request that touches PHI to the AuditLog table: user ID, patient ID, action, resource, IP address, timestamp. Logs are retained for 6 years (HIPAA requirement). Therapists can view their own audit log in Settings.

BAA (Business Associate Agreement)

TherapOS signs a BAA with every Solo and Clinic subscriber. BAAs are also signed with: AWS, Clerk, OpenAI, Anthropic, Stripe, and Resend before any PHI touches those systems.
