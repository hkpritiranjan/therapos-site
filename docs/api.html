API Reference

All endpoints are prefixed /api/v1. Authentication uses a Clerk JWT in the Authorization: Bearer <token> header. All responses follow {"data": ..., "meta": ...}.

Authentication

Authorization: Bearer <clerk_session_token>
Content-Type: application/json

Get the session token from Clerk's client SDK: await getToken(). All endpoints return 401 without a valid token and 403 when trying to access another therapist's data.

Patients

GET    /patients
  Query: ?status=active|inactive|all &q=search_string &page=1 &limit=20
  Returns: paginated patient list with basic profile

POST   /patients
  Body: { firstName, lastName, preferredName?, dateOfBirth?,
          primaryConcerns[], diagnoses[], modality?, sessionFreq? }
  Returns: created patient

GET    /patients/:id
  Returns: full patient profile + aiSummary + session count

PATCH  /patients/:id
  Body: partial patient fields
  Returns: updated patient

DELETE /patients/:id
  Soft-delete: sets status = DISCHARGED, sets endDate
  Returns: { success: true }

GET    /patients/:id/timeline
  Returns: all sessions + goals + homework in chronological order

GET    /patients/:id/sessions
  Query: ?page=1 &limit=20
  Returns: paginated sessions with note status

GET    /patients/:id/goals
  Returns: all goals with progressNotes array

GET    /patients/:id/homework
  Query: ?status=assigned|completed|all
  Returns: homework history

Sessions

POST   /sessions
  Body: { patientId, scheduledAt, sessionNumber, type? }
  Returns: created session

GET    /sessions/:id
  Returns: session + note (if exists) + aiPrep (if generated)

PATCH  /sessions/:id
  Body: { status?, rawNotes?, scheduledAt?, durationMins? }
  Returns: updated session

POST   /sessions/:id/start
  Marks session as IN_PROGRESS, sets startedAt
  Returns: updated session

POST   /sessions/:id/complete
  Marks session as COMPLETED, sets endedAt
  Returns: updated session

Notes

GET    /sessions/:id/note
  Returns: SessionNote or 404 if not created yet

POST   /sessions/:id/note
  Body: { format: "SOAP"|"DAP"|"BIRP"|"FREE",
          subjective?, objective?, assessment?, plan?,
          data?, dapAssessment?, dapPlan?,
          freeText? }
  Returns: created/updated note

PATCH  /sessions/:id/note
  Body: partial note fields (same as POST)
  Returns: updated note

POST   /sessions/:id/note/finalize
  Locks note, triggers embedding + summary refresh jobs
  Returns: { success: true, note: SessionNote }

AI Endpoints

POST   /ai/prep/:sessionId
  Generates AI session prep brief.
  Returns: SSE stream → final JSON:
    { recap, suggestedQuestions[], homeworkFollowUp, patterns }
  Cached: yes (re-use until rawNotes changes)

POST   /ai/note/draft
  Body: { sessionId, format: "SOAP"|"DAP" }
  Streams AI note draft token-by-token via SSE.
  Returns: SSE stream → final JSON note fields

POST   /ai/homework/suggest
  Body: { sessionId, goalIds?: string[] }
  Returns: { options: [{ title, description, category, rationale }] }

POST   /ai/summary/:patientId
  Regenerates rolling patient AI summary.
  Runs async (returns immediately, updates DB when done).
  Returns: { jobId: string }

Search

GET    /search
  Query: ?q=natural+language+query &patientId=optional
  Embeds query → cosine similarity search over NoteEmbedding
  Returns: [{ sessionId, patientId, snippet, score, date, patientName }]
  Example: GET /search?q=what coping strategies have worked&patientId=clx...

Goals

POST   /goals
  Body: { patientId, title, description?, category? }
  Returns: created goal

PATCH  /goals/:id
  Body: { status?, progressNote?: { note, sessionId? } }
  Returns: updated goal

DELETE /goals/:id
  Returns: { success: true }

Homework

POST   /homework
  Body: { patientId, sessionId?, title, description,
          category?, dueBy? }
  Returns: created homework

PATCH  /homework/:id
  Body: { status?, completedAt?, notes? }
  Returns: updated homework

Webhooks (internal)

POST   /webhooks/clerk
  Clerk webhook: user.created → create User row
                 user.updated → sync profile
                 user.deleted → soft-delete (retain audit logs)
  Verified via Clerk webhook signature

POST   /webhooks/stripe
  Stripe webhook: customer.subscription.updated/deleted
  Updates Subscription table

Error Codes

CodeMeaning
400Invalid request body (Zod validation failure — errors array included)
401Missing or invalid Clerk JWT
403Authenticated but accessing another therapist's data
404Resource not found (or not owned by this therapist)
429Rate limited — AI endpoints: 20 req/min per user
500Server error — check Sentry for details
503AI provider unavailable — product works without AI, retry later
