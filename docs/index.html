TherapOS Documentation

TherapOS is the AI-native operating system for independent therapists. Not an EHR. Not a therapy app. The clinical copilot therapists open before every session — and cannot practice without after 30 days.

✦
New here?

Follow the Quickstart guide to generate your first AI session note in under 10 minutes. No onboarding call required, no credit card needed.

What TherapOS Does

Independent therapists spend an average of 16 minutes per session writing notes — 35% of their working time on documentation. TherapOS collapses that to 3 minutes by turning raw bullet points into a clinically-worded SOAP or DAP note in under 12 seconds.

Speed is only the beginning. The real value is compound memory. Every finalized note makes the AI smarter about that patient. By session 10, TherapOS understands the treatment arc — patterns, progress, plateaus — better than any static EHR ever could. Session prep briefs, AI notes, and natural language search all draw from this accumulated context.

⚡ AI Session Notes

SOAP, DAP, BIRP, and free-text note drafts in 8–12 seconds from your raw notes. Always a draft — always editable, always your call.

🧠 Patient Memory

Rolling AI summaries updated after every note. Every AI call gets the full treatment arc as context — not just today's session.

🎯 Treatment Goals

🔍 Natural Language Search

What TherapOS Is Not

TherapOS deliberately excludes billing, insurance claims, scheduling, and telehealth. This is a feature, not a limitation. Keep SimplePractice for billing. Use TherapOS for everything clinical. Zero migration cost, zero switching risk, immediate value from session one.

Core Principles

  1. AI augments, never replaces. Every AI output is a draft. The therapist reviews, edits, and finalizes. The AI has no authority over the clinical record.
  2. Minimal clicks. The most common action — generate an AI note — takes two clicks. That's the standard for everything else.
  3. Everything searchable. Every note, goal, homework entry, and patient fact is findable via natural language. Nothing gets buried.
  4. Memory compounds. Patient context builds over sessions. The AI never starts from zero. Session 20 is contextually richer than session 1.
  5. No lock-in on exit. Export all patient data as JSON or PDF at any time. Your data is yours.
  6. HIPAA by default. Encryption, audit logs, and BAAs are not optional add-ons. They ship with every plan.

Key Concepts

Sessions and Notes

A Session is the scheduled meeting event — date, duration, type (Individual / Couples / Family / Group), and status (Scheduled / In Progress / Completed / Cancelled). A Session Note is the clinical documentation attached to that session. One session has exactly one note.

The note lifecycle: therapist inputs raw notes → AI generates a structured draft → therapist edits → therapist finalizes. Finalization triggers the async memory pipeline.

The Memory Pipeline

When a note is finalized, two BullMQ background jobs fire automatically:

  1. embed-note — converts the finalized note to a 1,536-dimensional vector using OpenAI's text-embedding-3-small and stores it in NoteEmbedding. Powers natural language search.
  2. refresh-summary — calls Claude Haiku with the last 3 finalized notes plus the existing summary, and generates a new 3–5 sentence patient summary. Stored in Patient.aiSummary. Injected into all subsequent AI calls for this patient.

Both jobs are async. The therapist sees the note as finalized immediately. Memory updates complete in 10–30 seconds in the background.

The AI-Is-Always-a-Draft Rule

No AI output in TherapOS is ever automatically saved or finalized. Every AI-generated field carries an AI Draft indicator. The therapist must explicitly click "Finalize" to commit a note to the clinical record. Any field can be edited or deleted before finalization. This is a product principle and a regulatory requirement — the therapist is always the decision-maker.
